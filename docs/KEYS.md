# Keys

If it does not appear on `?`, it does not exist. Native and web share the grammar (`G` then a letter, `J`/`K`, `E` done). Web has a longer map because it has more of the product (rules, snooze, calendar views).

## Native (0.2 compiled app)

| Key | Action |
| --- | --- |
| `J` / `↓` | Next thread |
| `K` / `↑` | Previous thread |
| `Enter` / `O` | Open / focus thread |
| `E` | Done (archive) |
| `#` | Trash |
| `C` | Compose |
| `R` | Reply |
| `Shift+R` | Reply all |
| `F` | Forward |
| `S` | Star |
| `U` | Undo last move |
| `Z` | Toggle unread |
| `Tab` | Focused / Other |
| `3` | Calendar |
| `?` | Keyboard reference |
| `Esc` | Close overlay / back |
| `Ctrl+K` / `/` | Command palette |
| `Ctrl+Enter` | Send (compose) |
| `G` then `I` | Inbox |
| `G` then `S` | Starred |
| `G` then `W` | Waiting |
| `G` then `D` | Drafts |
| `G` then `T` | Sent |
| `G` then `H` | Snoozed |
| `G` then `E` | Done |
| `G` then `#` | Trash |
| `G` then `C` | Calendar |
| `G` then `P` | Connect mailbox |
| `G` then `A` | Keyboard reference |

`G` is a 900 ms prefix. A second `G` does nothing useful; wait or hit the letter.

## Web

Hit `?` in the running client. Extra bindings:

| Key | Action |
| --- | --- |
| `H` | Snooze |
| `N` | File on calendar (from mail) / new event (from calendar) |
| `X` | Select |
| `M` | Mute |
| `L` | Label |
| `Y` | Summarize thread |
| `Shift+I` / `Shift+O` | Train person as Focused / Other |
| `,` | Settings |
| `\` | Two panes / three panes |
| `⌘↵` | Send — 8 seconds to undo |
| `1` / `2` | Mailbox 1 / 2 |
| `` ` `` | Cycle mailbox / calendar |
| `G` then `C` / `3` | Full calendar |
| `D` / `W` / `F` / `M` / `A` | Day / week / work week / month / agenda |
| `V` | Cycle calendar views |
| `Z` | Second time zone (calendar) |
| `T` | Today |
| `P` | Connect calendar (when calendar is open) |
| `R` | Sync calendar |

Snippets expand in compose with a semicolon (`;thanks`).
