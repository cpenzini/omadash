# Architecture

Omadash is two runtimes that share a keymap and a product. Only the native runtime is what we compile and hand to users.

```
native/          Flutter GTK client     ← compiled binary (the product)
  lib/src/store.dart    mailbox state
  lib/src/imap.dart     IMAP/SMTP + libsecret
  lib/src/keys.dart     Superhuman map
  lib/src/widgets/      Omarchy shell

src/             TanStack Start web     ← source, hosted / preview
  lib/mail/store.ts     zustand mailbox
  lib/mail/imap.server.ts
  lib/mail/calendar-sync.ts
  components/mail/      same chrome in the browser
```

## Native

A single-window Flutter app. `Omarchy.initialize()` loads `colors.toml`. `MailStore` hydrates, then `OmadashApp` → `MailShell`.

- **Offline first:** `buildSeed()` fills Alex Rivera’s inbox so keys work with the network down. Connecting IMAP replaces those threads.
- **IMAP:** `MailboxGateway.connect` opens `enough_mail`’s `ImapClient` to 993/TLS, logs in, `fetchRecentMessages`. Archive / trash `uidMove` (copy+delete fallback). Seen uses `uidMarkSeen` / `uidMarkUnseen`.
- **SMTP:** separate `SmtpClient` per send. STARTTLS on 587. PLAIN then LOGIN.
- **Secrets:** password in `flutter_secure_storage` (libsecret on Linux). Hosts, ports, identity in `shared_preferences`.
- **Keys:** `handleKey` in `keys.dart`. `G` arms a 900 ms prefix. Typing in an `EditableText` (compose, connect) swallows letters. `Ctrl+K` / `/` opens `showOmarchyCommandPanel`.
- **Layout:** `OmarchyScaffold` + `OmarchySplitPanel`. Sidebar hides under 500px (scratchpad / phone-width). Status bar: folder, unread, last IMAP error.
- **Calendar (0.2):** in-process list from `buildCalendarSeed`. No CalDAV yet.

GTK runner is generated by `native/tool/bootstrap.sh` (`flutter create --platforms=linux --no-overwrite`, then strip the header bar and show on first frame). We do not vendor `linux/` in git; CI and Omarchy both run bootstrap before `flutter build linux --release`.

The release tarball is that `bundle/` directory plus `install.sh` and `LICENSE`. The ELF binary is not relocatable without its `lib/` and `data/`.

## Web

TanStack Start on Vite. Zustand store, CSS variable themes, IMAP through server functions (`authMiddleware` + `user_id`). CalDAV (`tsdav`), Google Calendar, ICS. Better Auth for sign-in. Postgres (Neon) or PGLite in preview.

Browsers cannot open a raw IMAP socket (no TCP, CORS). That is why the compiled app exists.

Empty until connect. No demo inbox in the web client.

## What is not in the tarball

- `node_modules/`, Flutter SDK, `.dart_tool/`, `build/`
- App Builder / Grok preview internals (`AGENTS.md`, `.grok/`) — gitignored
- Secrets, `.env`

The GitHub source archive on each release is the full MIT tree.

## Versioning

One version string in three places:

- `native/pubspec.yaml` (`0.2.0+1`)
- `package.json`
- `src/lib/app.ts` (`APP_VERSION`)

Tag `v0.2.0`. The Linux job on that tag is the compile we publish.
