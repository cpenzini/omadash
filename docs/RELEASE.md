Omadash 0.2.0 — first compiled native release.

This is the GTK Linux binary. Download `omadash-0.2.0-linux-x64.tar.gz`, run `./install.sh`, bind Super+M.

```
tar -xzf omadash-0.2.0-linux-x64.tar.gz
cd omadash-0.2.0-linux-x64
./install.sh
```

```
bindd = SUPER, M, Omadash, exec, omadash
```

- Flutter + flutter_omarchy. No Electron.
- Theme follows Omarchy `colors.toml`.
- Live IMAP/SMTP (Gmail, Fastmail, iCloud, generic). App password in libsecret.
- Superhuman keys. Demo mailbox so they work offline.
- MIT source is this repository.
