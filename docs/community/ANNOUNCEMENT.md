# Omadash — native email for Omarchy, looking for early contributors

I'm building **Omadash**, an open-source native Gmail and Google Calendar client for Omarchy, using C++ and Qt.

The focus is fast keyboard triage, split inboxes, multiple accounts, and a clean interface that follows your Omarchy theme. Compose, search, reading, and calendar stay in the main window.

This is an **early contributor preview**, not a finished replacement for your mail client. Account restoration, account switching, and draft recovery have passed owner testing. Live sending is still under investigation, and HTML rendering needs broader validation. The demo uses fictional mail; no real messages are sent.

I'm looking for **five early testers and one or two C++/Qt contributors**. You can build and explore the sample workspace without a Google account. Connecting Gmail requires your own Google Desktop OAuth client.

Ways to help:
- Try the keyboard flows and report reproducible issues.
- Build the shortcut guide or contribute synthetic HTML rendering fixtures.
- Help with recipient suggestions, signatures, or split management.
